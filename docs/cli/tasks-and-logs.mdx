## lazycloud task

| Command | Description |
| --- | --- |
| `lazycloud task list [--limit <n>]` | Recent tasks (default limit 100). |
| `lazycloud task show TASK_ID` | Task detail: status, timing, deployment, container. |
| `lazycloud task result TASK_ID [--wait/--no-wait] [--timeout <s>]` | Print the task result; waits for completion by default. |
| `lazycloud task logs TASK_ID [--limit <n>]` | Recent log lines for the task (default 250). |
| `lazycloud task stop TASK_IDS...` | Stop one or more running tasks. |
| `lazycloud task cancel TASK_ID` | Cancel a pending task. |

```bash
lazycloud task list --limit 20
lazycloud task result 019...abc --timeout 60
```

## lazycloud logs

```bash
lazycloud logs [--task-id <id>] [--container-id <id>] [--deployment-id <id>] [--stub-id <id>]
```

Selects logs by exactly one source and prints or streams them:

| Flag | Description |
| --- | --- |
| `-n`, `--lines <n>` | Show the last N lines (default 250). |
| `-f`, `--follow` | Stream new logs as they arrive. |
| `--show-timestamp` | Include log timestamps. |
| `--max-events <n>` | Stop after N streamed log events (0 = unlimited). |

```bash
lazycloud logs --deployment-id dep-123 --follow --show-timestamp
```
