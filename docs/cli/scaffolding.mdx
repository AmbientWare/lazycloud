## lazycloud quickstart

```bash
lazycloud quickstart [-o <path>] [--force]
```

Writes the starter function app, `quickstart.py` by default. `--force`
overwrites an existing file. The [Quickstart](/getting-started/quickstart)
walks through it.

## lazycloud create-app

```bash
lazycloud create-app NAME [-o <path>] [--force]
```

Writes the starter app into a directory named `NAME`.

## lazycloud example

```bash
lazycloud example list
lazycloud example download NAME [-o <path>] [--force]
```

Lists and downloads starter templates. `quickstart` is the one available.
