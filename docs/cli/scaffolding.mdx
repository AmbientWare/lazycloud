## lazycloud quickstart

```bash
lazycloud quickstart
lazycloud run quickstart.py:hello LazyCloud
```

The first command writes `quickstart.py`; the second runs it on LazyCloud.
Use `-o <path>` for another filename. Existing files are preserved unless
you pass `--force`. See [Quickstart](/getting-started/quickstart) for sign-in
and expected output.

## lazycloud create-app

```bash
lazycloud create-app text_tools --output my-project
```

Writes `quickstart.py` and a README into `my-project`, with the app named
`text_tools`. Choose a name that starts with a lowercase letter and contains
lowercase letters, digits, or underscores. Omit `--output` to use the app
name as the directory.

## lazycloud example

```bash
lazycloud example list
lazycloud example download NAME [-o <path>] [--force]
```

Lists and downloads starter templates. `quickstart` is the one available.
The [guided examples](/examples/index) live in the repository and are not
downloaded by this command.
