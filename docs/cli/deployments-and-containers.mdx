## lazycloud app

An app is addressed by name or id.

```bash
lazycloud app list [--active | --inactive | --all]
lazycloud app show APP
lazycloud app pause APP      # stop every workload in the app
lazycloud app resume APP
lazycloud app delete APP
```

## lazycloud deployment

A deployment is addressed by name or id. `scale` sets the replica count for a Pod.
Functions and endpoints scale from their autoscaler configuration.

```bash
lazycloud deployment list [--app <name>] [--limit <n>]
lazycloud deployment stop IDS_OR_NAMES...        # scale to zero; the record stays
lazycloud deployment start ID_OR_NAME
lazycloud deployment scale ID_OR_NAME --containers <n>
lazycloud deployment delete ID_OR_NAME
```

```bash
lazycloud deployment list --app api_demo
lazycloud deployment scale web --containers 3
```

## lazycloud container

```bash
lazycloud container list [--limit <n>]                        # recent containers, default 100
lazycloud container attach CONTAINER_ID                       # stream output until it exits
lazycloud container checkpoint CONTAINER_ID [--checkpoint-id <id>]
lazycloud container stop CONTAINER_IDS...
```
