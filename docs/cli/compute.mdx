## lazycloud compute

```bash
lazycloud compute status       # capacity and the workspace's default pool
lazycloud compute instances    # running instances
lazycloud compute pools        # pools this workspace can use
lazycloud compute workloads    # which pool each workload runs in
lazycloud compute policy show
lazycloud compute policy update --default-pool <pool>
```

## lazycloud cloud

Connecting an AWS account needs the Team plan. The connection belongs to your
account and backs every workspace you own.

```bash
lazycloud cloud connect aws --account-id <id> [--role-arn <arn>] [--open]
lazycloud cloud status [--watch] [--until <phase>] [--interval <s>] [--timeout <s>]
lazycloud cloud validate            # recheck the current authorization
lazycloud cloud reconnect [--open]  # start a replacement authorization
lazycloud cloud cancel-reconnect
lazycloud cloud retry               # retry the connection's pending action
lazycloud cloud disconnect [--wait]
lazycloud cloud compute show
lazycloud cloud compute update [options]
```

`cloud status --until` accepts `awaiting_authorization`, `validating`,
`ready`, `degraded`, `reconnect_pending`, `retiring_authorization`,
`disconnect_draining`, `revoking`, `verifying_revocation`, and
`action_required`.

`cloud compute update` options: `--default-region`,
`--default-instance-type`, `--initial-cpu-workers`, `--min-cpu-workers`,
`--max-cpu`, `--max-gpu`, `--min-free-cpu-millicores`,
`--min-free-memory-mib`, `--allowed-region` (repeatable),
`--allowed-instance-type` (repeatable), `--idle-timeout` (60 to 86400
seconds), and `--root-volume-gib` (50 to 2048). An option you leave out keeps
its current value.

## lazycloud machine

```bash
lazycloud machine list
lazycloud machine join [options]     # run on the machine you are joining
lazycloud machine remove MACHINE_ID
```

`machine join` options:

| Option | What it does |
| --- | --- |
| `--pool <name>` | Pool to join, created if new. Default `self-hosted`. |
| `--gpu <model>` | GPU model this machine contributes. |
| `--max-cpu`, `--max-memory`, `--max-gpus` | Capacity to advertise, for example `--max-memory 32Gi`. |
| `--gpu-ids <ids>` | Comma-separated GPU device ids to expose, instead of `--max-gpus`. |
| `--background`, `--foreground` | Install the agent as a service (default) or run it in the terminal. |
| `--service-manager`, `--service-name`, `--state-dir` | Service installation details. |
| `--ttl <duration>` | Lifetime of the join credential. |
| `--print-only` | Print the install command instead of running it. |

Read the [host requirements](/platform/compute#your-own-machines) first.

## lazycloud domain

Custom domains need the Team plan.

```bash
lazycloud domain add HOSTNAME       # prints the DNS records to create
lazycloud domain status HOSTNAME
lazycloud domain list
lazycloud domain remove HOSTNAME
```

See [Custom domains](/platform/domains).
