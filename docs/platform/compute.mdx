title: "Compute"
description: "Where your workloads run: LazyCloud's compute, your own AWS account, or machines you join."
---

Your workloads run on LazyCloud's compute by default. You choose CPU, memory,
and GPU per workload, and pay per second while a container runs. Nothing else
is needed.

```python
@app.function(cpu=2.0, memory="4Gi", gpu="l4", gpu_count=1)
def embed(text: str) -> list[float]: ...
```

Available GPU models are `t4`, `a10g`, `l4`, `l40s`, `a100-40`, `a100-80`,
`h100`, and `h200`. Pass a list to state a preference, best first, and `"any"`
last to take whatever is free.

Check what your workspace is using:

```bash
lazycloud compute status
lazycloud compute instances
lazycloud compute workloads
```

## Pools

Every workload runs in a pool. The default pool is LazyCloud's own compute.
Connecting an AWS account or joining a machine adds capacity you own, and a
workload reaches it by naming the pool:

```python
@app.function(gpu="a10g", gpu_count=1, pool="aws")
def train(step: int) -> float: ...
```

The CLI equivalent is `--pool` on `deploy`, `run`, `serve`, `shell`, and
`dev`. To send every workload in a workspace to a pool without naming it each
time, set the workspace default:

```bash
lazycloud compute policy show
lazycloud compute policy update --default-pool aws
lazycloud compute pools
```

## Your own AWS account

On the Business plan you can connect one AWS account. LazyCloud then launches
instances inside your account when a workload asks for that pool, and shuts
them down when they go idle. Your data and containers stay in your account,
AWS bills you for the instances, and LazyCloud charges a management fee per
container instead of its compute rate. Volumes and egress are billed the same
as everywhere else.

The connection belongs to your account and serves every workspace you own.

```bash
lazycloud cloud connect aws --account-id 123456789012
```

Authorize the connection with your AWS profile. The command submits a
CloudFormation stack that creates the management role and network:

```bash
lazycloud cloud authorize --profile YOUR_AWS_PROFILE
lazycloud cloud validate
lazycloud cloud status --watch --until ready
```

The dashboard shows the same connection under Settings, then Compute. Once it
is ready, name the pool on a workload or make it the workspace default.

LazyCloud manages instance selection, regions, capacity limits, warm workers,
idle shutdown, and root disks. These settings apply to every workspace the
connection backs. Choose CPU, memory, GPU, and pool on each workload.

If the authorization stops working, for example after a role change in AWS,
`lazycloud cloud status` says so. `lazycloud cloud reconnect` starts a
replacement authorization, and `lazycloud cloud validate` rechecks the current
one. `lazycloud cloud disconnect` drains instances and removes the connection;
add `--wait` to block until it is gone.

## Your own machines

You can join a Linux server you own as capacity for every workspace you own.
This suits an on-premises GPU box, a bare-metal host, or a VM. Containers on
your own machines are not charged compute; volumes and egress still are.

The host needs:

- Linux on amd64 or arm64, with systemd and root or sudo access.
- A rootful Docker daemon.
- Outbound DNS and TCP port 443 for HTTPS and authenticated TLS connections.
  No inbound port, port forwarding, or static IP is needed.

Run the join on the machine itself:

```bash
lazycloud machine join --pool on-prem --gpu a100-80 --max-gpus 4 --max-cpu 32 --max-memory 128Gi
```

The command installs the agent as a background service. `--foreground` runs it
in the terminal instead, and `--print-only` prints the install command so you
can run it on another host. The command contains a short-lived credential; do
not share it. The machine joins the pool you name (`self-hosted` if you name
none) and creates the pool if it is new.

The dashboard has the same flow under Settings, then Compute, then Join a
machine, and shows the host checks as they pass.

```bash
lazycloud machine list
lazycloud machine remove <machine-id>
```
