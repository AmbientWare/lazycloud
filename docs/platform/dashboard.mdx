---
title: "Use the dashboard"
description: "Find run results, test an API, manage stored files, and check your spending."
---

Open [the dashboard](https://lazycloud.dev/dashboard) and choose your workspace
from the menu at the top.

## Find a result or investigate a failure

Open Tasks and select the run. Its detail view shows status, timing, retries,
the result or error, and logs. A task that is still pending shows why it is
waiting.

An app's page lists its workloads and recent activity.

## Test or stop a deployed service

Open the workload under Apps and use the request playground to send input.
Its controls scale, pause, resume, or delete it. Pausing stops serving without
removing the definition.

For a running sandbox, open its terminal, file browser, or process list from
the app page.

## Retrieve files

Storage contains volumes, artifacts, secrets, queues, and maps. The volume
browser holds shared files and the artifact browser holds task output. The
artifact browser searches filenames, filters by app, task, type, or date, and
previews or downloads files. A task's Artifacts tab shows that task's files.
The Storage page also shows total bytes stored and this month's storage
charges. Artifact downloads and public URLs follow the
[retention](/concepts/artifacts#retention) rules.

## Edit queues and maps

Open Storage, then Queues or Maps. Repeatable setup belongs in Python code, and
the dashboard suits inspecting data or a one-off correction.

For a map, select a key to view or edit its value and expiry. Saving fails if a
workload changed the key in the meantime. Reload and try again. You can inspect
and delete binary Python values but not edit them.

Choose Add key to create a key without overwriting an existing one. To create
a map, choose New map and enter its name and first key/value.

For a queue, Add message appends JSON to the end. Viewing the head message
does not remove it. Choose Remove next message to consume the next message
without running it. The dashboard then shows what it removed. Another consumer
can take the previewed message before you confirm, so the removed message may
be different. Choose New queue to create a named queue with its first message.

Deleting a queue removes its remaining messages. Deleting a map removes all
its keys. Both actions require confirmation and cannot be undone. Running code
can recreate a deleted collection with its next write.

## Check spending

Usage shows account spending by app and workload. The account total is the
same across workspaces you own.

Open Settings, then Billing to check your balance, payment method, plan, and
monthly usage limit. See [Plans and limits](/platform/plans) for what happens
when you reach a limit.

## Manage access and compute

In Settings, Tokens creates access tokens for scripts and direct HTTP calls.
Compute connects an AWS account or joins a machine, and shows each machine's
lifecycle phase. [Compute](/platform/compute) explains the phases. Domains
registers a hostname for your API.

The workspace menu creates and renames workspaces and manages members. An
owner or administrator invites people by email, changes roles, and removes
members. Opening an invitation link joins the workspace as whichever account is
signed in, even if its address differs from the one invited, so anyone who
opens the link takes the seat. Withdrawing or resending an invitation replaces
the earlier link. Anyone except the owner can leave a workspace from the
members dialog.
