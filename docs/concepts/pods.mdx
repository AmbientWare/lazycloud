A pod runs a container command, such as a web server or a model server.
Use one when you already have a command or image to run.

## Define a web server

Save this as `tools.py`:

```python
from lazycloud import App, Image

app = App("tools")

web = app.pod(
    name="web",
    image=Image(python_version="3.12"),
    command=["python", "-m", "http.server", "8080"],
    ports={"http": 8080},
    cpu=0.5,
    memory="256Mi",
    authorized=True,
)
```

Pods default to `cpu=1.0`, `memory="128Mi"`, `keep_warm=600`, and
`authorized=False`.

## Deploy it

Deploying a pod keeps it running under a deployment. The deploy output prints
its URL. This example serves the container's current directory and requires
a LazyCloud bearer token. Use the [vLLM example](/examples/openai-compatible-llm)
for a model server you can call from your application.

```bash
lazycloud deploy tools:app --resource pod:web
```

Manage it through the deployment, from Python with `web.scale(containers)`,
`web.pause()`, `web.resume()`, and `web.delete()`, or from the CLI:

```bash
lazycloud deployment list --app tools
lazycloud deployment scale web --containers 2
lazycloud deployment stop web
```

## Or create an instance on demand

A pod can also run once without a deployment. Set `LAZYCLOUD_TOKEN` to a
workspace access token, then fetch the directory listing and stop the instance:

```python
import os
import urllib.request

from tools import web

instance = web.create()
try:
    request = urllib.request.Request(
        instance.url,
        headers={"Authorization": f"Bearer {os.environ['LAZYCLOUD_TOKEN']}"},
    )
    with urllib.request.urlopen(request, timeout=60) as response:
        print(response.read().decode())
finally:
    instance.terminate()
```

`create()` uses the configured command. `web.run("python", "--version")`
starts an instance with a different command. Both return a `PodInstance`
with `container_id`, `url`, `timeout_seconds`,
`expires_at`, and `terminate()`. The instance lives for `keep_warm` seconds
unless you pass `timeout_seconds`.

## Options

`command` and `ports` describe what runs and what it listens on. `ports` maps
a name to a container port, for example `{"http": 8080}`. `env`, `secrets`,
and `volumes` inject configuration.

`authorized=True` requires a bearer token on the pod's HTTP URL.
`block_network=True` cuts outbound access;
`allow_list=[...]` restricts outbound access to IP networks in CIDR notation.
Hostnames are not supported.

`health_check_path` and `health_check_port` give the proxy an HTTP probe to
call before routing to a container. Without one, the proxy only checks that
the port accepts connections.

`checkpoint_enabled=True` lets you checkpoint a running pod. It needs
`checkpoint_readiness_path` and `checkpoint_readiness_port`, an HTTP probe
checked before the snapshot is taken.

`docker_enabled=True` gives the pod its own Docker daemon. `pool` picks the
compute pool.

`web.configure(...)` returns the pod with changed settings, and `web.shell()`
opens a shell in a pod container.

## TCP connections

Set `tcp=True`, declare the server's port, and use `pod.deploy()`. TCP ingress
requires a public Pod with `authorized=False` and a configured TLS ingress on
the installation. Standalone `pod.create()` rejects TCP before starting a container.
Your TCP server must authenticate its own clients if it handles private data.

The deployment returns a `tls://hostname:port` address. Connect with TLS and send
that hostname as SNI; the ingress forwards decrypted bytes to your server.

```python
import socket
import ssl
from urllib.parse import urlsplit

from lazycloud import App, Image

app = App("tcp_example")
tcp_server = app.pod(
    name="tcp-web",
    image=Image(python_version="3.12"),
    command=["python", "-m", "http.server", "8080"],
    ports={"http": 8080},
    tcp=True,
    authorized=False,
)

deployment = tcp_server.deploy()
address = urlsplit(deployment.invoke_url)
with socket.create_connection((address.hostname, address.port)) as connection:
    with ssl.create_default_context().wrap_socket(
        connection, server_hostname=address.hostname
    ) as stream:
        stream.sendall(b"GET / HTTP/1.0\r\n\r\n")
        print(stream.recv(1024))
```

This public example serves the container's directory over TLS. Stop it when
finished with `lazycloud deployment stop tcp-web`.

## Containers

Use container commands to investigate a running instance. Stop the deployment
when you want the service to remain stopped; stopping just its container can
cause the deployment to replace it. Pods incur compute charges while running.

```bash
lazycloud container list
lazycloud container attach <container-id>      # stream output until it exits
lazycloud container checkpoint <container-id>
lazycloud container stop <container-id>
```
