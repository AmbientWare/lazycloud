---
title: "Artifacts"
description: "Save files a task produces and share them with expiring public URLs."
---

An `Artifact` saves a file a task produced, such as an image, an archive, or a
report, into workspace storage. It stays attached to the task after the
container is gone.

## Save one

Inside a running task, the task id is picked up automatically:

```python
from lazycloud import App, Artifact

app = App("renders")


@app.function()
def render(frame: int) -> str:
    path = f"/tmp/frame-{frame}.png"
    ...  # write the file
    artifact = Artifact.file(path)
    artifact.save()
    return artifact.public_url(expires=3600)
```

`save()` uploads the file, zipping it first if the path is a directory, and
returns a `SavedArtifact` with `artifact_id`, `task_id`, and `filename`.
Outside a task, with no task id, `save()` packages the file on local disk
instead and returns a `SavedArtifact` without an `artifact_id`.

Other ways to construct one:

```python
Artifact.file(path, content_type=None, task_id=None)   # an existing file
Artifact.from_file(file_handle, suffix="")              # an open binary handle
Artifact.from_pil_image(image, format="png")            # a PIL image
Artifact(path=..., content_type=..., task_id=...)       # full control
```

`artifact.zip_dir(dir_path)` zips a directory so a folder can be saved as one
artifact.

## Retrieve one

`artifact.public_url(expires=3600)` returns a URL that serves the file without
authentication until it expires. Hand it to a browser or a webhook.
`artifact.exists()` and `artifact.stat()` check and describe the saved file.

Browse all workspace artifacts under **Storage → Artifacts** in the
[dashboard](/platform/dashboard), or open a task's Artifacts tab. Search filenames,
filter by app, task, type, or date, and preview or download files. Artifacts remain
accessible after the originating task is deleted. To save from outside the
producing container, pass `task_id=...` explicitly.

## Storage charges

Artifacts count toward **Volume storage**, at the same published storage rate as
volumes. Usage appears as **Artifacts**. Charges depend on the stored file's size
and how long it is retained, including files deleted between metering scans.
Directories are billed at their uploaded archive size.

The Storage page shows total bytes, the estimated monthly cost at the current
size, and accrued charges for the current UTC calendar month. Estimates exclude
future uploads, deletions, and account allowances. Billing continues until storage
confirms deletion, including when a deletion needs a retry.

Use `Artifact.save()` to persist an artifact. The implicit `/artifacts` mount is
read-only. For a writable shared filesystem, declare a `Volume` explicitly.

## Retention

Artifacts expire automatically using the same plan retention window as logs:
Free keeps them for one day, Team for 30 days, and Business for 90 days.
Complimentary accounts use the Business window.

The plan at upload determines the retention window. Expiration is measured from
when the upload succeeds, and later plan changes do not reset that deletion date.
There are no workspace or per-artifact retention settings. Read `saved.expires_at`
after `artifact.save()`, or see the deletion date in the dashboard.
Retention applies to remote storage, not locally packaged files.

Expired files become unavailable through the artifact API; background cleanup
removes their stored bytes. Newly issued public URLs cannot outlive the artifact's
expiration. Previously issued URLs may remain usable until their own expiry or
physical deletion. Files can be deleted earlier with `artifact.delete()`.

Artifacts saved before automatic retention was introduced receive at most one
plan retention window from rollout. An earlier scheduled deletion is preserved.
For durable files, use a Volume or download a copy before expiration.

## CLI

```bash
lazycloud artifact list --search report
lazycloud artifact usage
lazycloud artifact delete ARTIFACT_ID
```

Lists return a `next` cursor; pass it with `--cursor` to continue. Use `--workspace`
to select a workspace and the global `--json` option for machine-readable output.
