---
title: "Apps"
description: "An App owns the deployable resources registered under one application slug."
---

An `App` is the unit of organization. Every workload — functions, endpoints,
ASGI apps, task queues, cron jobs, pods, and sandboxes — is registered under an
app slug, which is the stable production identity used by deploy, serve, the
dashboard, and generated client handles.

```python
from lazycloud import App

app = App("billing")
```

Slugs must start with a lowercase letter and contain only lowercase letters,
digits, and underscores (up to 63 characters) — for example `"billing"` or
`"reporting_api"`.

## Registering resources

| Method | Registers |
| --- | --- |
| `@app.function(...)` | A remote [function](/concepts/functions) |
| `@app.cron("...")` | A [scheduled function](/concepts/cron) |
| `@app.endpoint(...)` | An HTTP [endpoint](/concepts/endpoints) |
| `@app.asgi(...)` | An ASGI application |
| `@app.realtime(...)` | A realtime WebSocket-style handler |
| `@app.task_queue(...)` | A background [task queue](/concepts/task-queues) |
| `app.pod(...)` | A long-running [pod](/concepts/pods) |
| `app.sandbox(...)` | An on-demand [sandbox](/concepts/sandboxes) |

Resource names must be unique per kind within an app; registering a duplicate
raises an error.

## Deploying an app

Deploy every deployable resource in the app:

```bash
lazycloud deploy billing_app.py:app
```

Or from Python:

```python
result = app.deploy()
```

`App.deploy` accepts a `resource` selector to deploy a single resource. Pass
the resource name, or `"kind:name"` when names overlap across kinds — for
example `"endpoint:api"` or `"task-queue:summarize"`:

```python
app.deploy(resource="endpoint:api")
```

The same selector is available on the CLI as `lazycloud deploy <handler> --resource
<selector>`. Sandboxes are created on demand and are not deployed by
`app.deploy()`.

## Serving an app

`App.serve` (or `lazycloud serve`) previews one endpoint, ASGI app, or task queue
resource on remote compute with live logs. When an app has more than one
serveable resource, select one:

```python
app.serve(resource="task-queue:summarize")
```
