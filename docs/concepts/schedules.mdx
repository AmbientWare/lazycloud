---
title: "Schedules"
description: "Run a Python function automatically at a set time or interval."
---

Set `cron` on a function and deploy it to schedule recurring work. Each
scheduled call has its own task record, result, and logs.

## Schedule a daily report

This function counts files in a volume every day at 03:00 UTC. Save it as
`daily_report.py`:

```python
from pathlib import Path

from lazycloud import App, Volume

app = App("daily_report")
uploads = Volume("report-inputs", "/inputs")


@app.function(name="count-files", cron="0 3 * * *", volumes=[uploads])
def count_files() -> dict[str, int]:
    count = sum(1 for path in Path("/inputs").rglob("*") if path.is_file())
    print(f"Stored files: {count}", flush=True)
    return {"files": count}
```

Deploy the function to register its schedule:

```bash
lazycloud deploy daily_report:count_files
```

The first invocation creates or reuses the declared volume. An empty volume
produces `{"files": 0}`. Upload your files to
`report-inputs` to count them on the next run.

## Choose a schedule

All schedules use UTC.

| When | Value |
| --- | --- |
| Every 15 minutes | `"*/15 * * * *"` |
| Mondays at 03:00 UTC | `"0 3 * * 1"` |
| Once an hour | `"@hourly"` |
| Every five minutes | `"every 5m"` |

Other aliases are `@daily`, `@midnight`, `@weekly`, `@monthly`,
`@yearly`, and `@annually`. Intervals support minutes up to 59, hours up
to 23, and days up to 31. Invalid expressions fail at deploy time.

## Try it now

```bash
lazycloud run daily_report:count_files
```

This runs once immediately and shows its logs and result. It does not wait
for the schedule. Review automatic runs in the dashboard or with
`lazycloud task list --app daily_report`.

Functions keep their normal timeout and retry settings. Scheduled functions
default to `keep_warm=0`, so a container shuts down when idle.

## Change or stop the schedule

Edit `cron` and deploy again to replace the schedule. Remove `cron` and
redeploy to keep the function callable without automatic runs.

To stop it now:

```bash
lazycloud deployment stop count-files
```

To remove the example entirely, delete the deployment with
`lazycloud deployment delete count-files`. Delete `report-inputs` only
after downloading any files you need.
