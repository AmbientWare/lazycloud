---
title: "Installation"
description: "Use uv to install the CLI and manage each project's Python environment."
---

Use uv for the CLI, project dependencies, and Python commands. Install
[uv](https://docs.astral.sh/uv/getting-started/installation/) first.

## Get the CLI

```bash
uv tool install lazycloud-client
lazycloud --help
```

This installs the `lazycloud` command in an isolated environment. Use it to
download an example or manage your account from any directory. It does not
install the SDK into another project's Python environment.

For a complete download-and-run example, follow the
[quickstart](/getting-started/quickstart).

## Add LazyCloud to an existing project

From your uv project:

```bash
uv add lazycloud-client
uv run lazycloud login
```

For a new project, run `uv init my-project` and `cd my-project` first.
Use `uv run lazycloud` for CLI workflows and `uv run python` for scripts.
The guides use this project environment by default.

Commit `pyproject.toml`, `uv.lock`, and the source. Keep `.venv` and
credentials out of version control. In CI, use `uv sync --locked` to require
the committed dependency versions.

The client supports Python 3.10 or newer. Downloaded examples select Python
3.12; uv can install that interpreter when needed. Remote Python and GPU
dependencies belong in the workload's `Image` definition.

## Upgrade deliberately

Upgrade the global tool:

```bash
uv tool upgrade lazycloud-client
```

For a project, run:

```bash
uv run lazycloud update
```

This updates the environment and lockfile within the constraints in
`pyproject.toml`. A downloaded example pins the SDK, so select the release
you want explicitly before upgrading:

```bash
uv add "lazycloud-client==<version>"
```

Review the changed dependency and lockfile, then rerun your workflow.
Downloading a newer example into a new directory lets you compare its code
without replacing your edits. Downloading never upgrades an existing project.

The CLI keeps sign-in state under `~/.lazycloud`; global and project commands
share it. Set `LAZYCLOUD_HOME` to use another location.
