---
title: "Installation"
description: "Install the lazycloud Python SDK and CLI."
---

The `lazycloud-client` package installs both the Python SDK (`import lazycloud`)
and the `lazycloud` command. It needs Python 3.10 or newer.

```bash
uv tool install lazycloud-client
```

or

```bash
pip install lazycloud-client
```

Check the install:

```bash
lazycloud --help
```

Upgrade later with the CLI itself. It upgrades through whichever installer
put it there (`uv tool`, `pipx`, `uv`, or `pip`):

```bash
lazycloud update
```

`lazycloud update --check` reports the installed and latest versions without
changing anything.

API responses tell the CLI which client version the server recommends. If yours
is older, the CLI prints a `lazycloud update` hint once per command. The hint goes
to stderr, including when you use `--json`. Requests continue normally.

The CLI keeps its sign-in state under `~/.lazycloud`. Set `LAZYCLOUD_HOME` to
put it somewhere else.
