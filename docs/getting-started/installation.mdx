---
title: "Installation"
description: "Install the lazycloud Python SDK and CLI."
---

Install `lazycloud-client` in the environment where you write your code. It
provides `import lazycloud` and the `lazycloud` command, and needs Python 3.10
or newer.

## Install in a project

For a uv project:

```bash
uv add lazycloud-client
```

Run commands with `uv run lazycloud` and scripts with `uv run python`.
The examples in these docs use `lazycloud` and `python` directly; add `uv run`
when using a uv project.

For an activated Python virtual environment:

```bash
python -m pip install lazycloud-client
```

## Install only the CLI

```bash
uv tool install lazycloud-client
```

This makes `lazycloud` available in your shell. It does not install the SDK
into the Python environment used by `python your_script.py`.

Check the install:

```bash
lazycloud --help
```

## Upgrade

Upgrade the installation you are running:

```bash
lazycloud update
```

For a uv project, run:

```bash
uv run lazycloud update
```

This updates `uv.lock` and the project's environment together, preserving the
dependency constraints in `pyproject.toml`. If a version pin prevents an upgrade,
the command reports it. Change the pin before retrying.

Global tools update through `uv tool` or `pipx`. Other environments use their
installer's pip command. The output identifies the installation and its environment
path. `lazycloud update --check` reports the installed and latest versions without
changing anything; use `uv run lazycloud update --check` to check a uv project.

If the CLI recommends an update, run it in the same environment as the command
you were using.

The CLI keeps its sign-in state under `~/.lazycloud`. Set `LAZYCLOUD_HOME` to
put it somewhere else.
