---
title: "Installation"
description: "Install the lazycloud Python SDK and CLI."
---

The `lazycloud-client` package installs both the Python SDK (`import lazycloud`)
and the `lazycloud` command. It needs Python 3.10 or newer.

```bash
uv tool install lazycloud-client
```

or

```bash
pip install lazycloud-client
```

Check the install:

```bash
lazycloud --help
```

The CLI keeps its sign-in state under `~/.lazycloud`. Set `LAZYCLOUD_HOME` to
put it somewhere else.
