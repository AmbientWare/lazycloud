title: "Serve your first endpoint"
description: "Deploy an HTTP API, send a request, and read its JSON response."
---

You'll deploy a POST endpoint that counts words in text. Start with the
[client installed](/getting-started/installation) and `lazycloud login` complete.

## Write the endpoint

Save this as `text_api.py`:

```python
from lazycloud import App

app = App("text_api")


@app.endpoint(name="word-count", route="/count", methods=["POST"])
def count_words(text: str) -> dict[str, int]:
    return {"words": len(text.split())}
```

LazyCloud maps the JSON request body to the function's arguments and returns
the dictionary as JSON.

## Deploy and call it

```bash
lazycloud deploy text_api:count_words
```

Copy the endpoint URL from the output. Endpoints require a bearer token by
default. Create an access token in Settings, then Tokens in the dashboard.
In Bash, read it without putting the value in shell history:

```bash
read -rsp "LazyCloud token: " LAZYCLOUD_TOKEN; echo
export LAZYCLOUD_TOKEN
export ENDPOINT_URL="<endpoint-url>"
curl --fail --show-error "$ENDPOINT_URL" \
  -H "Authorization: Bearer $LAZYCLOUD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Run Python on LazyCloud"}'
```

The response is `{"words": 4}`. Browser sign-in does not export
`LAZYCLOUD_TOKEN` for curl.

## Edit with a preview

When changing the code, use a temporary preview:

```bash
lazycloud serve text_api:count_words
```

Keep this terminal open. The command shows the preview URL and logs, and
syncs your edits. Send requests from a second terminal using that URL.
Press Ctrl+C to end the preview. Deploy again when you want the saved
deployment to use your changes.

## Call from Python

With `text_api.py` in your project, the decorated function is also a client:

```python
from text_api import count_words

response = count_words.target("deployed").request("Run Python on LazyCloud")
print(response.status_code, response.json())
```

The SDK uses your configured LazyCloud credentials.

## Stop the endpoint

When you're finished:

```bash
lazycloud deployment stop word-count
```

Use `lazycloud deployment start word-count` to restart it, or
`lazycloud deployment delete word-count` to remove the deployment.
