---
title: "Your first endpoint"
description: "Turn a typed Python callable into an HTTP endpoint and call it."
---

An endpoint is a Python callable with an HTTP route. Requests map to arguments,
the return value becomes the response, and warm workers stay up between calls.

## Write the endpoint

Save this as `api_demo.py`:

```python
from lazycloud import App, Image

app = App("api_demo")
image = Image(python_version="3.12")


@app.endpoint(name="predict", route="/predict", methods=["POST"], image=image)
def predict(value: int = 7) -> dict[str, int]:
    return {"input": value, "prediction": value + 1}
```

## Preview it

`lazycloud serve` runs the endpoint on LazyCloud with a temporary URL and
streams its logs to your terminal. It keeps your working directory synced into
the container as you edit, so this is the fastest way to iterate:

```bash
lazycloud serve api_demo.py:predict
```

## Deploy it

```bash
lazycloud deploy api_demo.py:predict
```

The deploy output prints the endpoint's URL. Endpoints require a bearer token
by default. Create one in the dashboard under Settings, then Tokens, and send
it in the `Authorization` header:

```bash
curl -X POST "<endpoint-url>" \
  -H "Authorization: Bearer $LAZYCLOUD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"value": 41}'
```

Set `authorized=False` on the decorator to make the endpoint public.

## Call it from Python

The decorated object is also a typed client. `.request(...)` calls the served
or deployed endpoint and returns a response with `status_code` and `json()`:

```python
response = predict.target("deployed").request(41)
print(response.status_code, response.json())
```

## Manage it

```bash
lazycloud deployment list --app api_demo
lazycloud deployment scale predict --containers 2
lazycloud deployment stop predict
```
