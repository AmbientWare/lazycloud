## 1. Sign in

```bash
lazycloud login
```

The CLI prints a link and a code. Open the link, check that the code matches,
and approve. The CLI is now signed in as you and can reach every workspace you
belong to. If you have more than one workspace, pick one:

```bash
lazycloud workspace list
lazycloud workspace use <name>
```

## 2. Write a function

Generate the starter file:

```bash
lazycloud quickstart
```

This writes `quickstart.py`:

```python
from __future__ import annotations

from lazycloud import App, Image

app = App("quickstart")
image = Image(python_version="3.12")


@app.function(name="hello", image=image, cpu=1.0, memory="256Mi")
def hello(name: str = "world") -> str:
    print(f"quickstart greeting for {name}", flush=True)
    return f"hello {name}"


if __name__ == "__main__":
    print(hello.local("lazycloud"))
```

Run it on your own machine first. `.local()` calls the plain Python function in
your process:

```bash
python quickstart.py
```

## 3. Deploy it

```bash
lazycloud deploy quickstart.py:hello
```

The handler reference is `<file-or-module>:<object>`: a path to a Python file
or an importable module, then the decorated object. Pass the `App` instead to
deploy everything it registers. The first deploy builds the image, so it takes
longer than the ones after it.

## 4. Call it

```bash
lazycloud run quickstart.py:hello LazyCloud
```

`lazycloud run` submits the call as a task on the deployed function and prints
the result. An argument that parses as JSON (a number, `true`, a list, an
object) is passed as that value; anything else is passed as a string.

## 5. Read the result and logs

Every call is a durable task:

```bash
lazycloud task list
lazycloud task show <task-id>
lazycloud task result <task-id>
lazycloud task logs <task-id>
```

`task result` waits for the task to finish. To follow logs as they arrive:

```bash
lazycloud logs --task-id <task-id> --follow
```

The same task appears in the dashboard under Tasks, with its status, result,
and logs.
