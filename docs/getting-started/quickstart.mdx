You'll run a Python function on LazyCloud, then add an HTTP endpoint to the
same file, deploy it, and call it with curl and from Python.

## Install and sign in

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then:

```bash
uv tool install lazycloud-client
lazycloud login
```

`login` prints a link and a code. Open the link, check that the code matches
your terminal, and approve.

## Run a function

Download the quickstart project and run its function:

```bash
lazycloud example download quickstart
cd quickstart
uv sync
uv run lazycloud run quickstart:hello LazyCloud
```

The command builds the image, uploads your code, runs `hello` in a remote
container, streams its logs, and prints `hello LazyCloud`. The first run takes
longer while the image builds; later runs reuse it.

This is `quickstart.py`:

```python
from __future__ import annotations

from lazycloud import App, Image

app = App("quickstart")
image = Image(python_version="3.12")


@app.function(name="hello", image=image, cpu=1.0, memory="256Mi")
def hello(name: str = "world") -> str:
    print(f"Greeting {name} from LazyCloud", flush=True)
    return f"hello {name}"


if __name__ == "__main__":
    print(hello.remote("LazyCloud"))
```

`quickstart:hello` names the module and the object in it. Arguments after it
are passed to the function. `uv run python quickstart.py` makes the same remote
call through `.remote()`.

If you belong to several workspaces, pick one first with
`uv run lazycloud workspace use <name>`.

## Add an endpoint

Add this to `quickstart.py`, above the `if __name__` block:

```python
@app.endpoint(name="greet", route="/greet", methods=["POST"], image=image)
def greet(name: str) -> dict[str, str]:
    return {"greeting": hello.local(name)}
```

The JSON request body maps to the function's arguments, and the returned
dictionary becomes the JSON response. `hello.local()` calls `hello` inside the
endpoint's own container.

Deploy the app:

```bash
uv run lazycloud deploy quickstart
```

This deploys both workloads and prints the endpoint's URL.

## Call it

Endpoints require a bearer token by default. Create an access token in the
[dashboard](https://lazycloud.dev/dashboard) under Settings, then Tokens, and
read it without putting it in your shell history:

```bash
read -rsp "LazyCloud token: " LAZYCLOUD_TOKEN; echo
export LAZYCLOUD_TOKEN
curl --fail --show-error "<endpoint-url>" \
  -H "Authorization: Bearer $LAZYCLOUD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "LazyCloud"}'
```

The response is `{"greeting": "hello LazyCloud"}`.

From Python, the decorated function is also a client. It uses your
`lazycloud login` credentials:

```python
from quickstart import greet

response = greet.target("deployed").request("LazyCloud")
print(response.json())
```

## Edit with a live preview

```bash
uv run lazycloud serve quickstart:greet
```

This runs the endpoint with a temporary URL and syncs your edits into the
container as you save. Change the greeting, send another request from a second
terminal, and see the change without redeploying. Press Ctrl+C to end the
preview, then deploy again when you want the deployment to use your changes.

## Clean up

```bash
uv run lazycloud app pause quickstart
```

This stops the app's workloads and keeps their definitions. Use
`uv run lazycloud app delete quickstart` to remove the app. Tasks, results, and
logs from these runs stay in the dashboard under Tasks.
