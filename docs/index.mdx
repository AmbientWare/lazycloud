---
title: "Run Python on LazyCloud"
description: "Run Python functions, serve APIs, and execute code in remote containers."
---

LazyCloud runs your code on remote CPUs and GPUs. Define the environment and
resources in Python, then run your function from a terminal or another Python
program. The client shows progress, logs, and the result.

Save this as `hello.py`:

```python
from lazycloud import App

app = App("hello")


@app.function()
def square(number: int) -> int:
    return number * number
```

With the [client installed](/getting-started/installation), sign in and run it:

```bash
uv run lazycloud login
uv run lazycloud run hello:square 12
```

The result is `144`. Follow the [quickstart](/getting-started/quickstart)
for the full walkthrough.

## What do you want to build?

| Goal | Start here |
| --- | --- |
| Run a batch job or call Python remotely | [Functions](/concepts/functions) |

| Host a container command or model server | [Pods](/concepts/pods) |

The [examples](/examples/index) walk through GPU inference, training,
document processing, a coding agent, and parallel data processing.

## Choose where it runs

LazyCloud supplies compute by default and charges per second while your
containers run. You can also [join your own machines](/platform/compute#your-own-machines)
or, on the Business plan, connect your AWS account. See
[Plans and limits](/platform/plans) for billing and account limits.
