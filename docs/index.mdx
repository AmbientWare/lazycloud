LazyCloud runs your code on remote CPUs and GPUs. Download the quickstart
project to run your first function. The client shows progress, logs, and the result.

<QuickstartRun />

The project includes the source and its Python environment definition. The
[quickstart walkthrough](/getting-started/quickstart) explains the function and
how to call it from Python. See [Installation](/getting-started/installation)
for adding LazyCloud to an existing project or upgrading the client.

## What do you want to build?

| Goal | Start here |
| --- | --- |
| Run a batch job or call Python remotely | [Functions](/concepts/functions) |
| Serve an HTTP API or a FastAPI app | [Endpoints](/concepts/endpoints) |
| Run a job on a schedule | [Schedules](/concepts/schedules) |
| Host a container command or model server | [Pods](/concepts/pods) |
| Execute generated code in a disposable container | [Sandboxes](/concepts/sandboxes) |
| Run 500 inputs at once, or keep a GPU warm | [Scaling and concurrency](/concepts/scaling) |
| Keep datasets and model weights between runs | [Volumes](/concepts/volumes) |
| Pass work items or share temporary state | [Queues and maps](/concepts/queues-maps) |
| Go from a local call to a preview to a deployment | [Local, preview, deploy](/getting-started/workflow) |

The [examples](/examples/index) walk through GPU inference, training,
document processing, a coding agent, and parallel data processing.

## Choose where it runs

LazyCloud supplies compute by default and charges per second while your
containers run. You can also [join your own machines](/platform/compute#your-own-machines)
or, on the Business plan, connect your AWS account. See
[Plans and limits](/platform/plans) for billing and account limits.
