LazyCloud runs Python on remote CPUs and GPUs. You add a decorator that says
what a function needs (packages, CPU, memory, GPU, storage), and LazyCloud
builds the container, uploads your code, runs it, and stops it when the work is
done. You pay per second while a container runs.

```python
from lazycloud import App, Image

app = App("reports")


@app.function(image=Image(python_version="3.12"), cpu=2, memory="4Gi")
def summarize(amounts: list[float]) -> dict[str, float]:
    return {"total": sum(amounts), "mean": sum(amounts) / len(amounts)}
```

The same file runs at each stage of development, with no change to the code:

```bash
uv run pytest                                           # test locally with summarize.local(...)
uv run lazycloud run reports:summarize '[12.5, 30, 8]'   # run once in the cloud
uv run lazycloud deploy reports                         # keep it available to other code
```

Each step is one non-interactive command with `--json` output and a nonzero exit
on failure, so a coding agent can test, run, and deploy the same way you do.
