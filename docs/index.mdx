LazyCloud runs your Python on remote compute. You decorate a function, deploy
it from your terminal, and every call becomes a durable task with a result and
logs. Sign in at [lazycloud.dev](https://lazycloud.dev), install the client, and
deploy.

```python
from lazycloud import App, Image

app = App("quickstart")
image = Image(python_version="3.12").add_python_packages(["httpx"])


@app.function(image=image, cpu=1.0, memory="512Mi")
def hello(name: str = "world") -> str:
    return f"hello {name}"


if __name__ == "__main__":
    print(hello.local("lazycloud"))
```

```bash
lazycloud deploy quickstart.py:hello
lazycloud run quickstart.py:hello LazyCloud
```

## What you can run

| Workload | Decorator | Use it for |
| --- | --- | --- |
| [Function](/concepts/functions) | `@app.function` | Remote Python calls, fan-out maps, background jobs |
| [Endpoint](/concepts/endpoints) | `@app.endpoint` | An HTTP route backed by a typed Python callable |
| [ASGI and realtime](/concepts/endpoints) | `@app.asgi`, `@app.realtime` | FastAPI and Starlette apps, WebSocket-style handlers |
| [Schedule](/concepts/schedules) | `@app.function(cron=...)` | A function that runs on a schedule |
| [Pod](/concepts/pods) | `app.pod(...)` | A long-running container command |
| [Sandbox](/concepts/sandboxes) | `app.sandbox(...)` | An on-demand container with process, file, and Docker control |

Workloads share [volumes](/concepts/volumes), [secrets](/concepts/secrets), and
[queues and maps](/concepts/queues-maps-signals). Every run shows up in the
[dashboard](/platform/dashboard) with its status, result, and logs.

## Where it runs

Your workloads run on LazyCloud's compute by default, and you pay per second
for what they use. On the Team plan you can also connect your own AWS account
or join your own machines. See [Compute](/platform/compute) and
[Plans and limits](/platform/plans).
