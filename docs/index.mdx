description: "LazyCloud is a Python-first serverless compute platform for functions, endpoints, scheduled jobs, pods, and sandboxes."
---

LazyCloud lets you write plain Python, decorate it, and run it on remote compute
with production semantics: durable tasks, retries, autoscaling HTTP workloads,
queues, volumes, secrets, and full observability.

```python
from lazycloud import App, Image

app = App("quickstart")
image = Image(python_version="3.12").add_python_packages(["httpx"])


@app.function(image=image, cpu=1.0, memory="512Mi")
def hello(name: str = "world") -> str:
    return f"hello {name}"


if __name__ == "__main__":
    print(hello.local("lazycloud"))
```

Deploy it with one command:

```bash
lazycloud deploy quickstart.py:hello
```

## What you can run

| Workload | Decorator | Use it for |
| --- | --- | --- |
| [Function](/concepts/functions) | `@app.function` | Remote Python calls, fan-out maps, background spawns |
| [Endpoint](/concepts/endpoints) | `@app.endpoint` | HTTP APIs from typed Python callables |
| [ASGI / Realtime](/concepts/endpoints) | `@app.asgi`, `@app.realtime` | FastAPI/Starlette apps and WebSocket-style handlers |
| [Cron](/concepts/cron) | `@app.cron` | Scheduled functions |
| [Pod](/concepts/pods) | `app.pod(...)` | Long-running command-style containers |
| [Sandbox](/concepts/sandboxes) | `app.sandbox(...)` | On-demand containers with process, filesystem, and Docker control |

## Where it runs

Your workspace schedules work onto compute you control:

- **Managed compute** operated by the platform you log in to.
- **Your own AWS account**, connected with `lazycloud cloud connect aws`.
- **Self-hosted machines** you join with `lazycloud machine join`.
