---
title: "Train a YOLO object detector"
description: "Train YOLO26n on an L4, keep the checkpoint in a volume, and predict from a second function."
---

This example trains a small detector in one GPU function and loads the
checkpoint in a second one. A `yolo-artifacts` volume keeps checkpoints,
metrics, and annotated images after both containers exit.

The default run trains on Ultralytics' eight-image COCO8 dataset for one
epoch. It is small enough to prove the whole workflow and is not an accuracy
benchmark.

The source is `examples/yolo_training/app.py` in the LazyCloud repository.

## The functions

Both share the pinned Ultralytics image and the volume:

```python
from lazycloud import App, GpuType, Image, Volume

image = Image.from_registry("ultralytics/ultralytics:8.4.101")
artifacts = Volume("yolo-artifacts", "/artifacts")
app = App("yolo_training")


@app.function(
    name="train-yolo",
    image=image,
    cpu=4,
    memory="16Gi",
    gpu=GpuType.L4,
    gpu_count=1,
    timeout_seconds=3600,
    retries=0,
    volumes=[artifacts],
)
def train_yolo(run_name: str = "coco8-smoke", epochs: int = 1, dataset_artifact: str | None = None):
    ...


@app.function(
    name="predict-yolo",
    image=image,
    cpu=2,
    memory="8Gi",
    gpu=GpuType.L4,
    gpu_count=1,
    timeout_seconds=900,
    retries=0,
    volumes=[artifacts],
)
def predict_yolo(training_run: str = "coco8-smoke", prediction_run: str = "bus-prediction", source_artifact: str | None = None):
    ...
```

The code calls the `yolo` executable with an argument list, not a shell
string, and resolves every caller-supplied path under `/artifacts`. Absolute
paths, `..`, and symlink escapes are rejected.

## Deploy

```bash
lazycloud volume create yolo-artifacts
lazycloud deploy examples.yolo_training.app:app
lazycloud deployment list --app yolo_training
```

Torch, CUDA, and Ultralytics stay inside the image; nothing is installed
locally.

## Train

With no arguments the function uses `coco8.yaml`, YOLO26n, and one epoch:

```bash
lazycloud run examples.yolo_training.app:train_yolo
```

The result names the checkpoint and metrics file. Inspect the run:

```bash
lazycloud task list --limit 10
lazycloud task logs <training-task-id>
lazycloud ls yolo-artifacts/training/coco8-smoke
lazycloud cp lazycloud://yolo-artifacts/training/coco8-smoke/results.csv ./results.csv
```

The L4 is charged only while the function runs. For this one-epoch run,
startup and the model download often take longer than training. Check the
Usage page before raising `epochs`, image size, or dataset size.

## Predict

The prediction function loads the saved `best.pt` and, by default, runs it on
Ultralytics' public `bus.jpg`:

```bash
lazycloud run examples.yolo_training.app:predict_yolo
lazycloud task logs <prediction-task-id>
lazycloud ls yolo-artifacts/predictions/bus-prediction
lazycloud cp lazycloud://yolo-artifacts/predictions/bus-prediction/bus.jpg ./bus-prediction.jpg
```

## Use your own data

Upload the dataset and its Ultralytics YAML to the volume. Paths inside the
YAML must point at files under `/artifacts` too.

```bash
lazycloud cp ./datasets/my-detector lazycloud://yolo-artifacts/datasets/my-detector
lazycloud run examples.yolo_training.app:train_yolo custom-run 50 datasets/my-detector/data.yaml
```

To predict on an uploaded image, pass its volume-relative path as the third
argument. The first two name the training run and the prediction run:

```bash
lazycloud cp ./sample.jpg lazycloud://yolo-artifacts/inputs/sample.jpg
lazycloud run examples.yolo_training.app:predict_yolo custom-run sample-prediction inputs/sample.jpg
```

Run names cannot be reused. Pick a new name for another run, or remove the
old run directory first, so a retry cannot overwrite a checkpoint.

## Clean up

Deleting the deployments stops future runs and keeps the volume:

```bash
lazycloud deployment delete train-yolo
lazycloud deployment delete predict-yolo
```

Remove runs you no longer need:

```bash
lazycloud rm yolo-artifacts/training/coco8-smoke
lazycloud rm yolo-artifacts/predictions/bus-prediction
```

Or delete the whole volume:

```bash
lazycloud volume delete yolo-artifacts --yes
```

<Warning>
  Deleting the volume deletes every checkpoint in it. Download what you want
  to keep first.
</Warning>
