This example separates model access from running generated code. A function
calls your OpenAI-compatible provider and returns one validated file
replacement. A network-blocked sandbox receives only the seed project and
that replacement, runs the unit test, and is terminated whether the test
passes, fails, or errors.

The source and seed project are under `examples/sandboxed_coding_agent/` in
the LazyCloud repository.

<ExampleSetup />

## What runs where

The deployed `plan-patch` function receives the provider base URL, model,
and API key as workspace secrets. The `test-patch` sandbox runs the generated
code with `block_network=True`.

The sandbox has no secrets, no outbound network, no exposed ports, and no
retained filesystem. The local orchestrator validates the planner's result
again before uploading anything.

The patch contract accepts complete UTF-8 content for `calculator.py` only.
It rejects absolute and traversal paths, unapproved or duplicate files,
control characters, more than three files, and more than 12,000 bytes. The
model cannot modify the test.

## Configure a provider

Use your provider's HTTPS base URL ending in `/v1`, the model name, and its
API key. The example appends
`/chat/completions` itself.

```bash
export CODING_AGENT_BASE_URL="https://provider.example/v1"
export CODING_AGENT_MODEL="provider-model-name"
read -rsp "Provider API key: " CODING_AGENT_API_KEY && echo
export CODING_AGENT_API_KEY

python -m examples.sandboxed_coding_agent.configure
unset CODING_AGENT_BASE_URL CODING_AGENT_MODEL CODING_AGENT_API_KEY
```

`configure.py` reads the names from the app's `PROVIDER_SECRET_NAMES` and stores
their environment values with `Secret(name).set(value)`. Running it again replaces
the stored values. The planner declares `secrets=list(PROVIDER_SECRET_NAMES)`;
the sandbox declares none. Keep the key out of the prompt, URLs, and source files.

<Warning>
  The planner sends the prompt and the seed source files to the provider you
  configure. Check that provider's data handling terms before pointing it at
  proprietary code.
</Warning>

## Deploy and run

Deploying the app deploys the planner. Sandboxes are created on demand.

```bash
lazycloud deploy examples.sandboxed_coding_agent.app:app
lazycloud run examples.sandboxed_coding_agent.app:run_agent
```

The default prompt asks the planner to fix the deliberately wrong
`calculator.add` without changing its test. The result includes the planner
task id, the terminated sandbox id, changed paths, the test exit code,
test output, and `tests_passed`. A successful repair returns `tests_passed: true`
and `test_exit_code: 0`. The command does not change your local seed project.

Pass a different instruction as the first argument:

```bash
lazycloud run examples.sandboxed_coding_agent.app:run_agent "Correct calculator.add and preserve its type hints."
```

## If the repair fails

```bash
lazycloud task show <planner-task-id>
lazycloud task logs <planner-task-id>
lazycloud run examples.sandboxed_coding_agent.app:inspect_sandboxes 20
```

Use the returned planner task ID to investigate provider failures. A failed
provider request creates no sandbox. For a failing test, read `test_output`
and revise the instruction. `test_exit_code` is the test process's exit code;
check `tests_passed` even when the CLI command itself completes.
The orchestrator terminates its sandbox in a `finally` block.

## Adapt the example

Each run costs your provider's tokens plus a short planner function and one
CPU sandbox. The seed project is tiny; costs grow with source size, model
pricing, and retries.

To work on another project, change the seed files and explicitly allowed
patch paths. Keep tests outside the model's editable files. Review generated
changes before applying them to a real repository; passing a test only proves
what that test checks.

## Clean up

The orchestrator terminates its sandbox. Delete the planner deployment and
the three secrets:

```bash
lazycloud deployment delete plan-patch
lazycloud secret delete CODING_AGENT_BASE_URL
lazycloud secret delete CODING_AGENT_MODEL
lazycloud secret delete CODING_AGENT_API_KEY
```
