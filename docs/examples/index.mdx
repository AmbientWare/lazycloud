## Before you begin

Install and authenticate the CLI, then select the workspace used by each guide:

```bash
lazycloud login
lazycloud workspace show
```

The GPU examples require available NVIDIA capacity and incur compute and model-download costs. The
storage examples create durable files that remain until you run their cleanup steps. Every guide
calls out its external credentials, licenses, retained resources, and teardown commands before the
first deployment.

<Note>
  These examples use current LazyCloud APIs and their real production backends. They do not include
  local-only substitutes for Tasks, Sandboxes, Volumes, object storage, or model execution.
</Note>
