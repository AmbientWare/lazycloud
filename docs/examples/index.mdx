the LazyCloud repository; clone the repository and run the commands in each
guide from its root, where `examples.<name>.app:app` is importable.

## Before you begin

```bash
lazycloud login
lazycloud workspace list
```

The GPU examples need GPU capacity and cost compute and model-download time.
The storage examples create volumes and files that stay until you run the
cleanup steps. Each guide names its external credentials, licenses, and
teardown commands before the first deploy.
