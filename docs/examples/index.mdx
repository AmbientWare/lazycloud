Choose the result you want, then follow the guide through setup, a first run,
and cleanup. Each guide uses source under `examples/` in the
[LazyCloud repository](https://github.com/AmbientWare/lazycloud/tree/main/examples).

Each app defines its images, compute, and storage mounts in Python. Run or
deploy it to use those definitions; mounted volumes need no separate CLI
creation step. Examples that need credentials include an explicit Python setup
step. CLI storage commands are for inspecting, downloading, and cleaning up data.

## Set up the examples

You need Python 3.12 or newer, uv, and access to the source repository. From
your checkout's root, create an environment for the examples:

```bash
uv venv .venv-examples --python 3.12
source .venv-examples/bin/activate
uv pip install ./packages/shared ./packages/lazycloud
```

These commands use Bash. Keep this environment active and run the guide's
commands from the repository root. Module references such as
`examples.yolo_training.app:train_yolo` depend on that working directory.
GPU libraries install in the remote images; you do not need a local GPU.

```bash
lazycloud login
```

If you use several workspaces, select one with `lazycloud workspace use <name>`.
Check your credit balance and GPU access in Settings, then Billing before
running a GPU example. The storage examples leave files behind so you can
reuse their outputs. Follow each guide's cleanup steps when finished.
