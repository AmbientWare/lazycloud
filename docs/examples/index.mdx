## Set up the examples

Install the CLI with uv, then choose a project:

```bash
uv tool install lazycloud-client
lazycloud example list
lazycloud example download image-studio
cd image-studio
uv sync
```

The download pins the SDK to the CLI you installed. Run each guide's commands
from the project directory. Commit the `uv.lock` that `uv sync` writes, since
remote images install from it. GPU libraries install only in those images, so
your machine needs no GPU.

```bash
uv run lazycloud login
```

With several workspaces, `uv run lazycloud workspace use <name>` picks one.
GPU examples need credit and GPU access, both under Settings, then Billing.
Volumes and artifacts outlast a run, and each guide ends with the commands that
remove them.

The catalog also has `quickstart`, `artifacts` and `all-workloads`, each with
its own README. `lazycloud example download all` writes every project to its
own directory.
