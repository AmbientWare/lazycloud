# Documentation

- Use Mintlify MDX and keep `docs.json` navigation current. Reuse snippets and
  give each fact one home; remove obsolete pages instead of preserving aliases.
- Document current public SDK/CLI workflows. Hosted-platform docs are not operator
  installation guides; avoid internal environment variables and wire identifiers.
- Keep examples runnable and aligned with typed configuration. Distinguish local
  code from remote execution and use public resource types such as `GpuType`.
- Name secret variables without values. Avoid repeating frontmatter in body copy.
