Install [uv](https://docs.astral.sh/uv/getting-started/installation/) if needed, then run:

```bash
uv tool install lazycloud-client
lazycloud login
lazycloud example download quickstart
cd quickstart
uv sync
uv run lazycloud run quickstart:hello LazyCloud
```

During login, open the link, check that the code matches your terminal, and
approve the sign-in. The example runs remotely and returns `hello LazyCloud`.
