Every workload decorator on `App` accepts these options:

| Option | Type | What it does |
| --- | --- | --- |
| `image` | `Image` | Container image the workload runs in. Defaults to the managed Python image. |
| `name` | `str` | Resource name. Defaults to the decorated callable's name. |
| `cpu` | `float` | CPU cores per container. |
| `memory` | `str` | Memory per container, for example `"512Mi"` or `"2Gi"`. |
| `gpu` | `str \| list[str]` | GPU model: `"t4"`, `"l4"`, `"a10g"`, `"l40s"`, `"a100-40"`, `"a100-80"`, `"h100"`, `"h200"`, or `"any"`. A list is a preference, best first: `["h100", "l4"]` takes an H100 where one is free and an L4 otherwise. `"any"` goes last. The two A100 sizes are separate names because they are not interchangeable, and plain `"a100"` is rejected. |
| `gpu_count` | `int` | GPUs per container. Defaults to `0`. |
| `env` | `dict[str, str]` | Plain environment variables. |
| `secrets` | `list[str]` | Workspace secret names, injected as environment variables. |
| `volumes` | `list` | `Volume` and `CloudBucket` objects to mount. |
| `authorized` | `bool` | Whether calls need a bearer token for the workspace. |
| `callback_url` | `str` | Webhook called with execution events. |
| `task_policy` | `TaskPolicy` | Scheduling policy for invocations. |
| `inputs` / `outputs` | schema | Optional schema metadata for clients and validation. |
| `docker_enabled` | `bool` | Give the container its own Docker daemon. |
| `preemptible` | `bool` | Defaults to `True`, allowing capacity that can be reclaimed. Set `False` to require non-preemptible capacity, including for GPU workloads. |
| `pool` | `str` | Compute pool to run in. See [Compute](/platform/compute). |
| `metadata` | `dict` | Custom metadata stored with the deployment. |

When a provider gives an interruption deadline, LazyCloud stops admitting new
calls to affected function and endpoint containers and starts replacements.
Calls already running can finish during the notice window. Remaining work is
stopped before the provider's deadline; interrupted function invocations follow
their retry policy. Save checkpoints for long-running work and make retries safe.
Providers can interrupt capacity without advance notice.

Use `@app.function(preemptible=False)` to opt out. This adds the CPU and memory
premium shown on the [pricing page](https://lazycloud.dev/pricing). It does not
add a GPU premium.
