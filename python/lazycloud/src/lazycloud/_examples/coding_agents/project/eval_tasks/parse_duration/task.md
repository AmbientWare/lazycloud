Implement `parse_duration(text)` in `durations.py`. It reads durations such as
`"1h30m"`, `"45s"` and `"2h5s"` and returns whole seconds. Units are `h`, `m`
and `s`, appear at most once each and in that order, and each takes a
non-negative integer. Anything else, including an empty string, raises
`ValueError`.
