`acceptance/neki/check.sh [-v]` runs every sqlc query through the production Neki router on a scratch database of its own, `lc_neki_check_` and a random suffix, and drops it afterwards, also on failure or interrupt, so concurrent runs never collide. It needs `AWS_PROFILE=default` access to `lazycloud-prod/platform`, exits non-zero on any router failure, and `-v` also lists ordinary PostgreSQL errors.
