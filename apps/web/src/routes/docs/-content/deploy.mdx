# lazycloud deploy

Deploys your Docker Compose app to the cloud.

```bash
lazycloud deploy --env shell --build-arg shell -y
```

## What Happens

1. Shows a diff of changes
2. Collects environment variables and build args from shell
3. Builds images remotely (if compose has `build:` configs)
4. Deploys with real-time progress

## Environment Variables & Build Args

Both are read from your shell. Environment variables are stored as encrypted secrets.

```bash
export DATABASE_URL=postgres://...
export API_KEY=secret123
export VITE_API_URL=https://api.example.com
lazycloud deploy --env shell --build-arg shell -y
```

## Deploy Specific Services

```bash
lazycloud deploy --env shell --build-arg shell -y -s api -s worker
```
