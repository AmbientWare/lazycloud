# Examples

Working applications you can deploy immediately or use as a starting point. Each example demonstrates different LazyCloud features.

## Available Examples

- [LLM Chatbot](/docs/examples/llm-chatbot) - Multi-service AI chatbot with streaming responses
- [Image Transformer](/docs/examples/image-transformer) - AI-powered image transformation with persistent storage
- [Stock Dashboard](/docs/examples/stock-dashboard) - Real-time stock data with zero configuration

## Quick Start

```bash
git clone https://github.com/AmbientWare/lazycloud-releases.git
cd lazycloud-releases/examples/llm-chatbot

# Test locally
export OPENAI_API_KEY=sk-...
docker compose up --build

# Deploy
lazycloud init
lazycloud deploy
```
