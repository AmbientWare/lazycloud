# Volume Labels

Configure persistent storage for your volumes. Add these to the top-level `volumes` section.

## lazycloud.volume.size

Set the storage size for a volume. **This label only applies to standard volumes.**

```yaml
volumes:
  db-data:
    labels:
      lazycloud.volume.size: '50Gi'

services:
  postgres:
    image: postgres:15
    volumes:
      - db-data:/var/lib/postgresql/data
```

**Default:** `10Gi`

**Supported units:**

- `Mi` - mebibytes (e.g., `500Mi`)
- `Gi` - gibibytes (e.g., `50Gi`)
- `Ti` - tebibytes (e.g., `1Ti`)

<Note>
  Shared volumes automatically scale up and down to match requested storage and
  do not require a volume size specification.
</Note>

---

## lazycloud.volume.shared

Mark a volume as shared storage for multi-replica access.

```yaml
volumes:
  shared-assets:
    labels:
      lazycloud.volume.shared: 'true'
```

| Value               | Storage Type | Use Case                              |
| ------------------- | ------------ | ------------------------------------- |
| `"false"` (default) | Standard     | Single-replica services               |
| `"true"`            | Shared       | Multi-replica or multi-service access |

<Note>
  Shared volumes automatically scale up and down to match requested storage.
  They do not require a `lazycloud.volume.size` specification.
</Note>

<Note>
  If a volume is mounted by multiple services, it's automatically marked as
  shared.
</Note>

---

## Full Example

```yaml
volumes:
  db-data:
    labels:
      lazycloud.volume.size: '50Gi'

  shared-assets:
    labels:
      lazycloud.volume.shared: 'true'

services:
  postgres:
    image: postgres:15
    volumes:
      - db-data:/var/lib/postgresql/data

  api:
    image: myapp:latest
    volumes:
      - shared-assets:/assets

  worker:
    image: myapp-worker:latest
    volumes:
      - shared-assets:/assets # Same volume, automatically scales
```

## Reference

| Label                     | Default   | Description                         |
| ------------------------- | --------- | ----------------------------------- |
| `lazycloud.volume.size`   | `"10Gi"`  | Volume size (standard volumes only) |
| `lazycloud.volume.shared` | `"false"` | Use shared storage (auto-scales)    |
