# lazycloud dashboard

Interactive terminal UI for monitoring deployments.

```bash
lazycloud dashboard
```

## Features

- View all deployments and their status
- Monitor service health in real-time
- View logs
- Trigger deployments and rollbacks

## Navigation

| Key            | Action   |
| -------------- | -------- |
| `↑/↓` or `j/k` | Navigate |
| `Enter`        | Select   |
| `q`            | Quit     |
| `?`            | Help     |

## Troubleshooting

If you see connection errors, re-authenticate:

```bash
lazycloud login
lazycloud dashboard
```
