# Service Labels

Add these labels to the `labels` section of any service in your Docker Compose file.

## lazycloud.domain

Set a custom domain for your service.

```yaml
services:
  api:
    image: myapp:latest
    ports:
      - "8080:8080"
    labels:
      lazycloud.domain: "api.example.com"
```

If not specified, LazyCloud auto-generates a unique domain for services with exposed ports.

---

## lazycloud.ignore

Exclude a service from deployment.

```yaml
services:
  app:
    image: myapp:latest

  debug-tools:
    image: debug:latest
    labels:
      lazycloud.ignore: "true"  # Won't be deployed
```

Useful for local-only services like debug containers or test databases.

---

## Reference

| Label | Default | Description |
|-------|---------|-------------|
| `lazycloud.domain` | auto-generated | Custom domain for the service |
| `lazycloud.ignore` | `"false"` | Skip deployment of this service |
