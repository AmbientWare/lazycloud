# Scaling Labels

Enable auto-scaling for your services. These labels go in the `deploy.labels` section.

## lazycloud.scaling.enabled

Enable or disable auto-scaling for a service.

```yaml
services:
  api:
    image: myapp:latest
    deploy:
      labels:
        lazycloud.scaling.enabled: "true"
```

---

## lazycloud.scaling.min / lazycloud.scaling.max

Set the minimum and maximum number of replicas.

```yaml
services:
  api:
    image: myapp:latest
    deploy:
      labels:
        lazycloud.scaling.enabled: "true"
        lazycloud.scaling.min: "2"
        lazycloud.scaling.max: "10"
```

| Label | Default | Description |
|-------|---------|-------------|
| `lazycloud.scaling.min` | `1` | Minimum replicas |
| `lazycloud.scaling.max` | `3` | Maximum replicas |

---

## lazycloud.scaling.cpu / lazycloud.scaling.memory

Set the CPU and memory utilization thresholds that trigger scaling.

```yaml
services:
  api:
    image: myapp:latest
    deploy:
      labels:
        lazycloud.scaling.enabled: "true"
        lazycloud.scaling.cpu: "70"
        lazycloud.scaling.memory: "80"
```

| Label | Default | Description |
|-------|---------|-------------|
| `lazycloud.scaling.cpu` | `70` | Scale up when CPU exceeds this % |
| `lazycloud.scaling.memory` | `70` | Scale up when memory exceeds this % |

---

## Full Example

```yaml
services:
  api:
    image: myapp:latest
    ports:
      - "8080:8080"
    deploy:
      replicas: 2
      labels:
        lazycloud.scaling.enabled: "true"
        lazycloud.scaling.min: "2"
        lazycloud.scaling.max: "10"
        lazycloud.scaling.cpu: "70"
        lazycloud.scaling.memory: "80"
```

## Reference

| Label | Location | Default | Description |
|-------|----------|---------|-------------|
| `lazycloud.scaling.enabled` | `deploy.labels` | `"false"` | Enable auto-scaling |
| `lazycloud.scaling.min` | `deploy.labels` | `1` | Min replicas |
| `lazycloud.scaling.max` | `deploy.labels` | `3` | Max replicas |
| `lazycloud.scaling.cpu` | `deploy.labels` | `70` | CPU threshold % |
| `lazycloud.scaling.memory` | `deploy.labels` | `70` | Memory threshold % |
