# Compose Labels

Customize your deployment behavior using LazyCloud-specific labels in your Docker Compose file.

## Label Types

### [Service Labels](/docs/labels/service)

Control how individual services are deployed.

- `lazycloud.domain` - Set a custom domain
- `lazycloud.ignore` - Exclude from deployment

### [Scaling Labels](/docs/labels/scaling)

Enable auto-scaling for your services.

- `lazycloud.scaling.enabled` - Enable auto-scaling
- `lazycloud.scaling.min` / `lazycloud.scaling.max` - Replica limits
- `lazycloud.scaling.cpu` / `lazycloud.scaling.memory` - Scaling thresholds

### [Volume Labels](/docs/labels/volume)

Configure persistent storage.

- `lazycloud.volume.size` - Set volume size
- `lazycloud.volume.shared` - Enable shared storage

---

## Quick Reference

| Label | Location | Default | Description |
|-------|----------|---------|-------------|
| `lazycloud.domain` | `services.*.labels` | auto-generated | Custom domain |
| `lazycloud.ignore` | `services.*.labels` | `"false"` | Skip deployment |
| `lazycloud.scaling.enabled` | `services.*.deploy.labels` | `"false"` | Enable auto-scaling |
| `lazycloud.scaling.min` | `services.*.deploy.labels` | `1` | Min replicas |
| `lazycloud.scaling.max` | `services.*.deploy.labels` | `3` | Max replicas |
| `lazycloud.scaling.cpu` | `services.*.deploy.labels` | `70` | CPU threshold % |
| `lazycloud.scaling.memory` | `services.*.deploy.labels` | `70` | Memory threshold % |
| `lazycloud.volume.size` | `volumes.*.labels` | `"10Gi"` | Volume size |
| `lazycloud.volume.shared` | `volumes.*.labels` | `"false"` | Shared storage |
