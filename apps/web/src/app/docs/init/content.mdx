# lazycloud init

Creates a `.lazycloud` config file linking your project to a deployment.

```bash
lazycloud init
```

## Options

| Option | Description |
|--------|-------------|
| `-n, --name` | Deployment name |
| `-f, --file` | Compose file to use |
| `--force` | Overwrite existing config |

## Examples

```bash
# Interactive (prompts for name, detects compose files)
lazycloud init

# Specify name
lazycloud init --name my-app

# Use specific compose file
lazycloud init --file docker-compose.prod.yml
```

## The Config File

```yaml
deployment_name: my-app
compose_file: docker-compose.yml
```

Commit this file so your team deploys to the same place.

## Syncing Existing Deployments

If the deployment name already exists, you'll be prompted to sync it locally. Useful when cloning a project that's already deployed.
