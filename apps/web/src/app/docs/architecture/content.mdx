# Architecture

How LazyCloud runs your applications.

| Topic | Description |
|-------|-------------|
| [Networking](/docs/architecture/networking) | Service communication, network isolation, domains |
| [Builds](/docs/architecture/builds) | Cloud-based image builds with Depot |
| [Scaling](/docs/architecture/scaling) | Auto-scaling based on CPU and memory |
| [Volumes](/docs/architecture/volumes) | Persistent storage for your data |
| [Secrets](/docs/architecture/secrets) | Environment variables and encrypted storage |
| [Resources](/docs/architecture/resources) | CPU and memory limits |
| [Security](/docs/architecture/security) | Container isolation with gVisor |

LazyCloud deploys your Docker Compose applications to managed infrastructure. You write standard compose files—LazyCloud handles the rest.
