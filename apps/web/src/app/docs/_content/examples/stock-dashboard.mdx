# Stock Dashboard

Real-time stock analytics built with Python. No JavaScript framework—just FastAPI, HTMX, and Tailwind CSS.

<Tip>
**What you'll learn:** The simplest possible deployment—no secrets, no volumes, no environment variables. Just build and deploy.
</Tip>

```
┌─────────────────┐     ┌─────────────┐
│    FastAPI      │────▶│   Yahoo     │
│  + HTMX + TW    │     │   Finance   │
└─────────────────┘     └─────────────┘
```

## Features

- **Search any stock** by ticker symbol (AAPL, GOOGL, TSLA, etc.)
- **Real-time data** from Yahoo Finance (free, no API key)
- **Price charts** with adjustable time periods
- **Key metrics** including market cap, P/E ratio, 52-week range
- **HTMX partial updates** for instant UI without page reloads
- **In-memory caching** with 5-minute TTL

## Prerequisites

None! This example uses Yahoo Finance which requires no API key.

## Quick Start (Local)

```bash
git clone https://github.com/AmbientWare/lazycloud-releases.git
cd lazycloud-releases/examples/stock-dashboard

# Install dependencies and run
uv sync
uv run uvicorn main:app --reload
```

Open [http://localhost:8000](http://localhost:8000) to use the dashboard.

## How It Works

The app uses a simple stack:

| Component | Purpose |
|-----------|---------|
| **FastAPI** | Python web framework with async support |
| **HTMX** | Partial page updates without JavaScript |
| **Tailwind CSS** | Styling via CDN |
| **Chart.js** | Interactive price charts |
| **yfinance** | Free stock data from Yahoo Finance |

Stock data is cached in-memory for 5 minutes to reduce API calls. Since there's no persistent storage, the cache resets on container restart—which is fine for this use case.
