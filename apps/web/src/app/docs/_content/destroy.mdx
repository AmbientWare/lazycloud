# lazycloud destroy

Removes a deployment and all its resources.

```bash
lazycloud destroy
```

## Options

| Option | Description |
|--------|-------------|
| `-f, --force` | Skip confirmation |

## Examples

```bash
# From project directory
lazycloud destroy

# By name
lazycloud destroy my-app

# Skip confirmation
lazycloud destroy --force
```

## What Gets Deleted

- Containers
- Volumes (data is lost)
- Networks
- Secrets

> **Warning:** This is irreversible. All volume data is permanently deleted.

Your `.lazycloud` file remains, so you can redeploy later.
