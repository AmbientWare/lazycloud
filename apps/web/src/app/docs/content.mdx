# Getting Started

Deploy Docker Compose applications to the cloud in minutes.

## Install

**Mac / Linux:**
```bash
curl -LsSf https://lazycloud.dev/install.sh | sh
```

**Windows:**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://lazycloud.dev/install.ps1 | iex"
```

## Login

```bash
lazycloud login
```

## Deploy Your First App

```bash
cd my-project
lazycloud init
lazycloud deploy
```

That's it. Your app is now running in the cloud.

## Monitor

```bash
lazycloud dashboard
```

## Clean Up

```bash
lazycloud destroy
```

## Help

```bash
lazycloud --help
```
