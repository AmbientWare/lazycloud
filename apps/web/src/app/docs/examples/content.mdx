# Examples

Complete applications ready to deploy. Each example includes a Dockerfile, compose.yaml, and working application code.

| Example | Stack | Features Demonstrated |
|---------|-------|----------------------|
| [FastAPI LLM](/docs/examples/fastapi-llm) | Python, FastAPI, OpenAI | Secret injection, uv builds |
| [Go API](/docs/examples/go-api) | Go | Multi-stage builds, minimal images |
| [Next.js](/docs/examples/nextjs) | TypeScript, React | Standalone output, SSR |

## Quick Start

```bash
git clone https://github.com/AmbientWare/lazycloud-releases.git
cd lazycloud-releases/examples/fastapi-llm

lazycloud init
lazycloud deploy
```

## Structure

Each example follows standard Docker Compose conventions:

```
example-name/
├── compose.yaml     # Services, ports, health checks
├── Dockerfile       # Container build
└── ...              # Application source
```

No LazyCloud-specific configuration required. If it runs with `docker compose up`, it deploys with `lazycloud deploy`.
