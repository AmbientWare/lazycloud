# Examples

Reference implementations demonstrating LazyCloud features. Each example is a working application you can deploy immediately or use as a starting point.

| Example | Stack | Features |
|---------|-------|----------|
| [LLM Chatbot](/docs/examples/llm-chatbot) | Next.js, FastAPI, SQLite, Redis | Multi-service, volumes, secrets |

## Quick start

```bash
git clone https://github.com/AmbientWare/lazycloud-releases.git
cd lazycloud-releases/examples/llm-chatbot

# Test locally
export OPENAI_API_KEY=sk-...
docker compose up --build

# Deploy
lazycloud init
lazycloud deploy
```

## Structure

```
llm-chatbot/
├── compose.yaml      # Service definitions + LazyCloud labels
├── frontend/         # Next.js (port 3000)
└── api/              # FastAPI + OpenAI (port 8000)
```

Standard Docker Compose—no LazyCloud-specific files required. Labels in `compose.yaml` configure deployment behavior.
