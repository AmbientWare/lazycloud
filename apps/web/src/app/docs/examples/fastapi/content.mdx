# FastAPI Example

A simple FastAPI application with a health check endpoint, ready to deploy with LazyCloud.

## Files

### main.py

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def read_root():
    return {"message": "Hello from LazyCloud!"}


@app.get("/health")
def health_check():
    return {"status": "healthy"}
```

### pyproject.toml

```toml
[project]
name = "fastapi-example"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = [
    "fastapi>=0.115.6",
    "uvicorn>=0.34.0",
]
```

### Dockerfile

```dockerfile
FROM python:3.12-slim

WORKDIR /app

COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv

COPY pyproject.toml .
RUN uv sync --no-dev

COPY main.py .

CMD ["uv", "run", "uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### compose.yaml

```yaml
services:
  api:
    build: .
    labels:
      lazycloud.expose: "8000"
      lazycloud.healthcheck.path: "/health"
```

## LazyCloud Labels Explained

| Label | Value | Description |
|-------|-------|-------------|
| `lazycloud.expose` | `8000` | Exposes port 8000 publicly with HTTPS |
| `lazycloud.healthcheck.path` | `/health` | Health check endpoint for zero-downtime deploys |

## Deploy

```bash
# Get the example
git clone https://github.com/AmbientWare/lazycloud-releases.git
cd lazycloud-releases/examples/fastapi

# Initialize and deploy
lazycloud init
lazycloud deploy
```

## Local Development

```bash
uv sync
uv run uvicorn main:app --reload
```

Visit http://localhost:8000 to see your API running locally.
