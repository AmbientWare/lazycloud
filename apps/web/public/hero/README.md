# Earth texture

`earth.jpg` is NASA's Blue Marble Next Generation map for December 2004,
with topography and bathymetry, resized to 2048 × 1024 for the landing animation.

Credit: NASA Earth Observatory.

[Source collection](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/)
