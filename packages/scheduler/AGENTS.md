# Scheduler Package

Own queueing, assignment, autoscaling, capacity, worker/fleet hot state, route
publication, retries, and cancellation behind typed Redis repositories. Durable
history stays in explicit database owners; endpoint/pod/gateway/worker/process
composition stays in apps. Preserve leases, concurrency, retries, assignment,
and terminal cancellation through real coordination and, when lifecycle changed,
one representative worker request.
