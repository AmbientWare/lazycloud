# Images Package

Own image planning, durable records/events/metadata, lifecycle decisions,
execution/publication control, and cleanup behind scheduler, container, storage,
and secret protocols. Apps, SDK, provider adapters, and scheduler/worker loops
remain outside. Managed-runtime catalogs hold one content-addressed artifact per
supported Python minor and keep managed code separate from fallback dependencies.
Preserve credentials, durability, concurrency, terminal failure, publication,
load, and cleanup through the affected real path.
